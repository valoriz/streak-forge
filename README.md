# streak-forge
Streak.js framework and static site generator for building fast, modern websites, including the CLI, project scaffolding, rendering engine, and documentation.

## Why Split the Monorepo
- Separate **public framework** from **private platform code**
- Independent development and releases
- Simpler CI/CD and testing
- Better security and access control
- Easier maintenance and scaling
- Clear ownership for each product
 
 
## streak-forge — Public
- Streak.js framework
- Static site generator / rendering engine
- CLI & create-streak-app
- SPA capabilities
- Documentation site
- Examples/templates
